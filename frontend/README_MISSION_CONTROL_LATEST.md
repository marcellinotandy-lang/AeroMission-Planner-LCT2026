# Latest Mission Control Frontend

Финальная визуальная версия интерфейса находится в обновленном пакете сдачи на Google Drive:

https://drive.google.com/drive/folders/1N4fHkZ5UFOO86H7pKiWt5BcRGy-I6NFk

Причина отдельного файла: финальный frontend был пересобран вместе с презентацией, документацией и ZIP-пакетом, чтобы жюри получило согласованный набор файлов.

Что в финальной версии UI:

- тёмный mission-control экран;
- центральная карта с зоной работ, no-fly зонами, галсами и маршрутами;
- KPI-панель: время работы, суммарный налёт, покрытие, число галсов, активные БВС;
- правый валидатор плана: нарушения, безопасность, предупреждения, выбранный вариант;
- нижний таймлайн по флоту;
- экспорт GeoJSON/KML.
