# AeroMission Planner

Интеллектуальный сервис планирования и распределения беспилотных авиационных работ для кейса Геоскан / ЛЦТ 2026.

Сервис принимает координаты ВПП, парк БВС, область съемки, тип полезной нагрузки, разрешенное воздушное пространство, бесполетные зоны, резервные площадки и ветер. На выходе формируются индивидуальные полетные задания для каждого БВС с маршрутом, высотой, скоростью, точками старта/посадки, последовательностью этапов и экспортом в GeoJSON/KML.

## Что реализовано

- веб-интерфейс для запуска тестового сценария и редактирования входного JSON;
- backend API на FastAPI;
- алгоритм построения галсов съемки по полигону;
- учет бесполетных зон, разрешенного ВП, резервных площадок и ветра;
- распределение галсов между БВС по 3 режимам: минимум времени, минимум суммарного налета, баланс;
- проверка выполнимости по батарее и заданному сроку;
- экспорт полетных заданий в GeoJSON и KML;
- тесты API и планировщика.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
```

Открыть в браузере: `http://localhost:8000`.

## Запуск тестов

```bash
pytest -q
```

## Структура

```text
backend/app/main.py              FastAPI, статический фронт, export API
backend/app/models.py            Pydantic-схемы входа и выхода
backend/app/planner/core.py      генерация галсов и распределение по БВС
backend/app/planner/pathfinding.py обход бесполетных зон через visibility graph
backend/app/planner/exporters.py GeoJSON/KML
frontend/                        веб-прототип без сборки
examples/demo_scenario.json      демонстрационный сценарий
docs/                            документация для сдачи
```

## API

- `GET /api/health` — проверка сервиса.
- `POST /api/plan` — построить план по JSON-сценарию.
- `POST /api/export/geojson` — экспорт результата планирования.
- `POST /api/export/kml` — экспорт результата планирования.

## Примечание по постановке

Вопросы из чата учтены в решении: пользователь сам задает ограничения по количеству БВС/сроку, система сообщает выполнимость, выбор модели БВС производится исходя из задачи, камеры абстрагированы через тип съемки и инженерную ширину полосы покрытия, высота ограничивается 150 м.
