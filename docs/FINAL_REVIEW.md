## Команды проверки

```bash
pip install -r requirements.txt
pytest -q
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
```

Открыть `http://localhost:8000`, нажать «Рассчитать план полётов», затем выгрузить GeoJSON/KML.
