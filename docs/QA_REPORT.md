# QA report

Дата проверки: 2026-09-29.

## Проверенный состав решения

- backend API на FastAPI;
- веб-интерфейс Mission Control UI;
- алгоритм построения галсов, распределения БВС и обхода no-fly зон;
- демо-сценарий на 10 БВС;
- экспорт GeoJSON/KML;
- Docker, CI, тесты, документация и презентация.
